# 第二阶段功能规划：新增 50 项开发相关工具

> 目标 2️⃣ 的施工图。新增节奏：**每批 4–6 件**，每件从零落实 i18n（三份 string.json + 中英元数据）、
> 无障碍（accessibilityText/语义）、关怀模式（scaled() 字体），并用系统组件设计页面。
> 每批完成后跑十道门禁 + 真机逐件验证。

## 通用纪律（每件工具都适用）

- **纯逻辑与 UI 分离**：`<ToolId>Logic.ets` 零 import 可单测；`<ToolId>Page.ets` 只做渲染。
- **文案三层**：元数据用 `NGFLocalizedText`（双语）；固定标签用 `$r('app.string.*')`（三份 string.json）；
  错误文案走 `*Messages.ets` 码→文案映射。**先写英文再写中文同审**，避免「中文为主英文补译」。
- **无障碍**：所有可点图标必带 `accessibilityText`；状态类文本不只用颜色区分（加图标/文字）。
- **关怀模式**：字号一律 `scaled()`，关键行高用 `scaled()` 参与，禁止写死 vp 字号。
- **页面形态**：优先框架 `NGFPageTemplates`（列表/表单形状）；输入区→处理→输出区→操作行的节奏
  与现有 16 件保持一致；动效随第 4️⃣ 项统一补。
- **加键须三处同步**：base/zh_CN/en_US 三份 string.json，键名加 `tool 前缀_` 避免与框架撞键。
