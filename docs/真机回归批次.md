### 已知的自动化障碍：部分 TextInput 写不进去

「迭代计算」的日期输入框：点击 → `uitest uiInput inputText` → `uinput -K -t` 三种方式都试过，
回读仍是空（placeholder 未被替换）。而同一套方法在别处可用。

**第 105 轮复核后的硬结论**：

- 首页搜索框的 `inputText` **可用**（手册 §3.4.8.6 记过 5/5）；
- **工具页的 TextInput 一律写不进去**——`uitest uiInput inputText <x> <y> <text>` 与
  `uinput -K -t` 都试过，坐标用的是 `dumpLayout` 的精确 bounds（`[629,607][1170,742]` 这种），
  回读仍是空。

**所以回归策略定为**：

- **能自动验的**：首屏渲染、按钮、错误态、只读表数据、`[object Object]` 之类的文案缺陷；
- **不能自动验的**：任何「输入 → 出结果」的路径，标为「需人工」；
- **别再试第三种输入姿势**——两次足够定性。

### 复核方式

1. 点分类页签 → 截图看卡片；
2. 点卡片进工具页 → 截图看首屏；
3. 有结果区的，优先找**无需输入即可触发**的路径（如默认值、示例按钮）；
4. 返回用 `uinput -K -d 2 -u 2`。

坐标：`uitest dumpLayout` 的 bounds **就是** `uinput` 的物理坐标，截图只是缩小预览（×1.5）。

## 首屏验证脚本模板（第 106 轮跑通，直接复制进 run_code）

**要点**：pwsh 负责 `hdc`（`file recv` 只有 pwsh 里能正常落盘），Node 负责解析与判定。
**不要**在 Node 的 `execSync` 里调 `hdc file recv` —— 它静默不产出文件。

```ts
const wait = (ms) => { const s = new Int32Array(new SharedArrayBuffer(4)); Atomics.wait(s, 0, 0, ms); };
const pw = (cmd) => tools.pwsh({ command: cmd, description: 'device op', workdir: WD, timeoutMs: 118000 });
const hd = (args) => pw('& "' + HDC + '" -t ' + T + ' ' + args);
const dump = async () => {
  await hd('shell uitest dumpLayout -p /data/local/tmp/x.json');
  await hd('file recv /data/local/tmp/x.json "./_x.json"');
  return fs.readFileSync('_x.json', 'utf8');
};
// 找文本中心点（bounds 就是 uinput 物理坐标）
// 判定：标题在 / 无 [object Object] / 有 Button
```

**流程**：`aa start` → 确认首页（找「搜索工具」）→ 点页签(406/611/817/1022, 2637)
→ 先滚回顶部 3 次 → 循环「dump 找卡片 → 找到就点 → dump 验页 → BACK 回首页」。

**两个必须做对的地方**（都踩过）：

1. **每件开始前先 `ensureHome`**：dump 找「搜索工具」，找不到就 `aa start` 恢复前台再试 BACK。
   **不要在验证结束后无条件 BACK**——验证失败时人还在首页，那一按会把 App 退到后台
   （本轮实际撞到前台变成酷安，之后每一步都无效，白跑两件）。
2. **找卡片前先滚回顶部**（`swipe 500 900 500 2200`），否则只在当前滚动位置找，
   工具明明在下面却报「卡片未找到」。

### 方法突破：「列表测绘」一次性拿到整页布局

TEXT 页签有 40+ 件工具、共 5 屏。靠「滚动 N 次找某一件」既慢又容易错过（本轮 TOML 就因此漏了三次）。

**改为先测绘、再按图索骥**：从顶部开始，每滚一屏 dump 一次，把**每屏可见的工具名**记下来。
测绘结果直接给出了每件工具在第几屏 —— 之后每件只需「滚顶 12 次 + 滚 N 次 + 点」。

TEXT 页签实测 5 屏：

| 屏 | 工具 |
|---|---|
| 0 | 正则测试 / MD 预览 / URL 编解码 / 命名风格转换 / 文本行工具 / HTML 实体 / 占位文本生成 / JSON 工具 |
| 1 | JSON 路径取值 / 表单解析 / TOML 解析 / YAML 解析 / SQL 格式化 / 正则速查 / 文本哈希校验 / ASCII 分隔线 |
| 2 | ASCII 分隔线 / Git 速查 / 快捷键速查 / JSON 转接口文档 / 更新日志生成 / 正则替换预览 / Base64 图片预览 / 链接检查 |
| 3 | Base64 图片预览 / 链接检查 / 实体速查 / Cron 解析 / Shell 速查 / 代码压缩预览 / 文档目录生成 / Cron 速查 |
| 4 | 键盘符号速查 / ASCII 对照表 / 表格生成 / 字符频率 / 文本换行 / 行号添加器 / 十六进制转储 / 文本 Diff |

> **两条配套修正**：
> 1. 「滚回顶部」要 **12 次**才够（2 次只回到一半，后面全错位）；
> 2. 找卡片的 y 上限放到 **2520**（2400 会把屏幕最下面那张卡切掉）。

> **另一个高效模式**：把「回首页 + 切页签 + 滚顶 + 滚 N 次 + dump」合并进**一次 pwsh**
> （PowerShell 里用 `1..N | ForEach-Object { ... }`），避免每步一次工具调用。
