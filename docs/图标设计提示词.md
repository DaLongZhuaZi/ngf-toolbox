# 图标设计提示词（foreground 生成专用）

> 用途：交给生图 Agent 只生成分层图标的**上层 foreground**，与仓库已对齐的家族 background 合成最终图标。
> 家族基准：电波足迹（AirwaveFootprints）的上架图标。风格关键词先说清，避免跑偏：
> **家族图标是「亮蓝底 + 浅蓝玻璃窗格」，不是电波足迹宣传图的深色荧光绿**——宣传图与图标是两套视觉，生图时以本文件为准。

## 一、家族风格规格（实测自电波足迹图标原文件）

| 项 | 规格 |
|---|---|
| background | 纯色 **#0962F2** 亮蓝，1024×1024。**已从电波足迹原样复制进本仓**（AppScope 与 entry 各一份），不需要生成、不要改 |
| foreground | **1234×1234，RGBA，窗格以外完全透明**（四角 alpha=0） |
| foreground 主体 | 一块「玻璃浏览器窗格」：浅蓝磨砂玻璃质感、圆角矩形，占画布约 86% 居中；顶部有窗格标题栏（与主体一条细分隔线），标题栏左上角有 **3 个小圆角方点**（窗口控制点），右上角有一颗 **四角星闪光（sparkle）** |
| 窗格内部 | 左上区放一个白色小 motif（电波足迹是「足迹 + 信号弧线」）；下半部居中放 **大号粗体缩写字母**（电波足迹是 AWF），白色→浅蓝竖向渐变、圆润无衬线、带轻微内阴影与描边 |
| 边缘 | 干净锐利的矢量感边缘（电波足迹原图边缘略有毛边，是旧图缺陷，**新图不要学**） |

## 二、主案提示词（直接粘贴给生图 Agent）

### 中文版

```
生成一张应用图标的上层前景图（foreground），1234×1234，PNG，背景完全透明，只画主体、不要画任何底色。

主体是一块「玻璃窗格」风格的图标牌：圆角矩形，浅蓝色磨砂玻璃质感，带柔和的高光与通透感，占画布约 86% 并居中。窗格顶部有一条标题栏，与下方主体用一条细线分隔；标题栏左上角有 3 个并排的小圆角方形窗口控制点（白色半透明），右上角有一颗小小的四角星闪光装饰。

窗格内部布局：左上区域（标题栏下方）放一个简约的白色线性小图标——由终端命令提示符「>_」与一把小扳手组合而成，线条圆润、极简；窗格下半部居中放三个大号字母「NGF」，粗体圆润无衬线字体，白色到浅蓝色的竖向渐变填充，带轻微内阴影和细描边，字母间距宽松，视觉分量与上方小图标形成「小 motif + 大字母」的经典布局。

整体风格：明亮、通透、科技感的浅蓝玻璃拟物风，干净扁平的矢量边缘，柔和阴影，不要深色，不要绿色，不要照片写实。
```

### English version

```
App icon foreground layer only, 1234x1234 PNG, fully transparent background — draw only the subject, no backdrop color.

The subject is a frosted-glass "browser window" plaque: a rounded rectangle in translucent light-blue glass with soft highlights, occupying about 86% of the canvas, centered. A title bar runs across the top, separated from the body by a thin line; on the left of the title bar are three small rounded-square window control dots in semi-transparent white, and a small four-point sparkle sits at the top-right corner.

Inside the plaque: in the upper-left area below the title bar, place a small minimalist white line glyph combining a terminal prompt ">_" with a small wrench, rounded and clean. In the lower half, centered, place the large bold letters "NGF" in a rounded sans-serif, filled with a white-to-light-blue vertical gradient, subtle inner shadow and thin outline, generous letter spacing — a classic "small motif above, big letters below" layout.

Style: bright, airy, techy light-blue glass skeuomorphism, clean vector-sharp edges, soft shadows. No dark colors, no green, no photorealism.
```

### 反向提示词（negative）

```
不要背景底色，不要方形实心底板（主体外必须透明），不要深色，不要绿色/荧光绿，不要文字（NGF 三个字母除外），不要出现中文，不要写实照片风，不要 3D 金属，不要边缘毛边/撕纸边/光晕外溢，不要把字母画歪或多画字母，不要多余的小图标堆砌
```

## 三、备选变体（主案 motif 替换，其余描述不变）

- **变体 B**：左上 motif 换成「一个打开的工具箱剪影（带提手），箱盖上方浮着小扳手与螺丝刀的白色线条图标」。
- **变体 C**：去掉独立 motif，把终端提示符「>_」放大到左上区作为唯一 motif（更极客、更简洁）。

## 四、生成后验收清单

- [ ] 尺寸 1234×1234、PNG、四角透明（alpha=0），主体外无任何像素残留
- [ ] 与 background（#0962F2）在 DevEco 图标预览或任意合成预览中叠看：窗格居中、占比约 86%、不溢出
- [ ] 字母只有 N、G、F 三个，无错字、无多余笔画；小尺寸（48px 等效）下仍可辨认
- [ ] 无深色、无绿色、无中文、无额外文字
- [ ] 边缘干净，无毛边/撕纸感

## 五、落地步骤（验收通过后）

1. 替换两处 foreground（保持文件名不变）：
   - `AppScope/resources/base/media/foreground.png`
   - `entry/src/main/resources/base/media/foreground.png`
2. `background.png` 与 `layered_image.json` 不动。
3. 在 `docs/开发交接.md` 的图标条目上把状态改为「正式图标已替换（日期）」，并提交。
